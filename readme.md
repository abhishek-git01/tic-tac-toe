# Tic-Tac-Toe Game

A C++ console-based Tic-Tac-Toe game where the player competes against the computer.

## Features

- Player vs computer gameplay
- 3x3 dynamic game board
- Win detection
- Loss detection
- Tie detection
- Input validation
- Prevents moves on occupied positions
- Replay option

## Technologies Used

- C++
- Arrays
- Loops
- Conditional Statements
- Functions
- Random Number Generation

## How to Run

1. Compile `Tic_Tac_Toe.cpp` using a C++ compiler.
2. Run the generated executable.
3. Enter a position from 1 to 9 to place `X`.
4. The computer places `O` automatically.
5. Choose `Y` or `N` when asked to play again.
